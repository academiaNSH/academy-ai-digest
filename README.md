# Академия начальной школы — AI-дайджест

Небольшой сайт-дайджест про искусственный интеллект для учителей: 10 карточек
с материалами, фильтр по темам и страницы материалов.
Отдельно живёт выпуск 2 — «Подготовка урока с помощью нейросетей».
Сделан на Flask, HTML, CSS и чистом JavaScript.

## Что внутри

- Главная страница с героем, бегущей строкой, фильтрами и сеткой карточек.
- 10 материалов с разделами, списками и блоком «Забрать с собой».
- Отдельная страница выпуска 2 с десятью шагами подготовки урока.
- Страница 404 и полоса прогресса чтения.
- Светлая «рисованная» тема: рукописные заголовки, пунктирные рамки, жёлтый
  маркер, цветные акценты у каждой темы.
- Адаптив от узких телефонов до широких мониторов.

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:5000.

## Статическая версия для GitHub Pages

GitHub Pages не умеет запускать Python, поэтому для него собирается статичная
копия сайта в папке `docs/`:

```bash
python build_static.py
```

Скрипт рендерит те же шаблоны в HTML-файлы, копирует `static/` и кладёт
`.nojekyll`. Страницы лежат в одной папке, ссылки относительные — сайт
работает и на GitHub Pages, и при открытии `docs/index.html` с диска.

Живая версия: https://academiaNSH.github.io/academy-ai-digest/

## Структура

```
app.py              маршруты Flask и обработка 404
materials.py        контент: категории и 10 материалов
issues.py           данные отдельного выпуска 2
templates/          base.html, index.html, material.html, vypusk.html, 404.html
static/css/         style.css — вся тема и адаптив
static/js/          main.js — фильтры, анимации, прогресс
static/img/         логотип и его уменьшенные версии
```

## Как добавить материал

Достаточно дописать ещё один словарь в список `MATERIALS` в `materials.py` —
карточка, страница и блок «Читать дальше» появятся автоматически.

## Как добавить выпуск

Добавьте выпуск в словарь `ISSUES` в `issues.py` — страница `/vypusk/<номер>`,
ссылка в шапке и анонс на главной появятся автоматически.
